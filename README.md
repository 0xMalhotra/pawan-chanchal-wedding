A beautiful, interactive wedding invitation website for **Pawan & Chanchal**  
**Date:** Tuesday, 20th October, 2026  
**Venue:** Rajaji Hotel & Banquets, Jind (HR)

## ✨ Features
- 🌸 Animated floating petals canvas
- ⏱️ Live countdown timer to the wedding date
- 🃏 3D card tilt effects on hover
- ✨ Cursor sparkle trail
- 🔵 Scroll-reveal animations
- 🗺️ Embedded Google Maps + location link
- 📱 Fully responsive (mobile-first)
- 💬 WhatsApp RSVP button
- 🌐 Vercel-ready static deployment

## 🚀 Deploy to Vercel

### Option 1: Via Vercel CLI
```bash
npm i -g vercel
cd d:\PawanChanchal
vercel --prod
```

### Option 2: Via Vercel Dashboard
1. Go to [vercel.com](https://vercel.com) and log in
2. Click **"Add New Project"** → **"Import Git Repository"**
3. Push this folder to GitHub first, then import it
4. Or drag & drop the folder in the Vercel dashboard

### Option 3: Drag & Drop
1. Zip the `PawanChanchal` folder
2. Go to [vercel.com/new](https://vercel.com/new)
3. Drag and drop the zip file directly
